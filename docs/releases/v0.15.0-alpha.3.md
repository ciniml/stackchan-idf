- **Wi-Fi RTP 音声受信の音飛びを修正** (CoreS3): L16 48 kHz のライブ音声がプチプチ途切れていた問題。原因は 3 つ — 7 月以降 CoreS3 だけ Wi-Fi 受信バッファが減らされていた、パケットがまとめて届くと取りこぼしていた、再生バッファが満杯のまま回って揺らぎのたびに音を捨てていた — をすべて直しました。受信中は Wi-Fi の省電力を切り、送信側と機体のクロック差 (±0.3 % 程度) は再生側で滑らかに吸収します (ピッチの揺れなし)。再生開始までの遅れは約 200 ms
