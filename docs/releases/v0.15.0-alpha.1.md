- **リップシンクとストリーミング発話** (by @mongonta0716, #7): 発話を句ごとに合成して再生を始めるので、長い文でも待ち時間が短くなりました。母音に合わせて口の形が変わり、吹き出しの字幕も発話に同期して進みます。sanoTTS / HMM / フォルマント / 単位連結のどのエンジンでも句読点で自然な間が入ります
- **アバターのアクセサリ**: 顔 DSL に `accessories` / `accessory_0..7` 変数が増え、設定ページの「アクセサリ」チェックで表示を切り替えられます。同梱の顔 (デフォルト / オメガ口 / あおっこ) はスロット 0 で首輪と鈴を描きます
- **顔 DSL の `mouth_form`**: 口の幅を開き具合と独立に指定できます (#7)
- **吹き出し**: 左詰め表示になり、溢れるときだけ文頭から一度スクロールします。前の吹き出しの完了通知で次の吹き出しが消える不具合を修正 (#7)
- **アイドル発話の順序**: ランダム / 連続 を設定ページで選べます (#7)
- **リリース チャンネル**: アルファ版と正式版を分けました。Web Flasher / 設定ページの「チャンネル」で表示範囲を選べます (既定は正式のみ)。この alpha は CoreS3 / AtomS3R のみ
- **修正**: StopWatch の BLE 設定ページで sanoTTS が「エンジン無し」と表示される / HMM ボイス (hts_engine) のメモリ確保サイズ (#7)
