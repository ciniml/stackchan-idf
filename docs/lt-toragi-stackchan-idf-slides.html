04複数の設定方法

Bluetooth
  • 基本的な設定が可能
  • Wi-Fi の接続設定も Bluetooth 経由
Web Bluetooth の設定ページから。X25519 + AES-256-GCM でアプリ層暗号化
Wi-Fi
  • Bluetooth の設定項目とほぼ同等
  • 高速・安定した通信
  • ファームウェア アップデートなど大きいデータの転送
機体の HTTP サーバ + mDNS stackchan-XXXXXX.local
SoftAP + QR
  • ブラウザで Bluetooth が使えない iOS 向け
  • QR を読むと自動で接続先切替・設定ページ表示
未設定時は AP を立てて LCD に Wi-Fi QR (キャプティブポータル)
未設定時の LCD — SSID / PW / URL 入りの Wi-Fi QR

08前回 (9 月の M5 Japan Tour) からのアップデート

v0.13 → v0.15.0-alpha.2 (2026-09)。すべて既存機体にブラウザから入れられます
ニューラル音声合成 sanoTTS-jp
ESP32-S3 上で動く小さな日本語 TTS。重みは機体が公式サイトから自分で取得 (再ビルド不要)
リップシンクとストリーミング発話
句ごとに合成して話し始め、母音で口の形が変わり、吹き出しの字幕が同期。by @mongonta0716 (PR)
近接センサーで反応 (CoreS3)

アクセサリ
顔 DSL から参照できるアクセサリ スロット。標準の顔は首輪と鈴を描く (ON/OFF 可)
更新の仕組みを刷新
専用の Recovery 領域経由で更新。設定ページでリリースを選ぶと機体が Wi-Fi で取りに行く (BLE から指示可)
アルファ版チャンネル
Web Flasher / 設定ページの「チャンネル」で alpha を選ぶと検証版を入れられる。正式版は既定のまま

09その他の機能・これからの機能
